# Bluevera Residences

Repositorio común de web y marketing. Es también la memoria de trabajo del equipo con Claude Code: empieza por [CLAUDE.md](CLAUDE.md).

- `contexto/` — empresa, cliente, marca, conocimiento local
- `decisiones/` — decisiones pendientes de consolidar (`archivo/` para las incorporadas)
- `web/` — código Next.js ([web/CLAUDE.md](web/CLAUDE.md), [web/estado.md](web/estado.md))
- `marketing/` — [marketing/estado.md](marketing/estado.md) y campañas

Conectores en `.mcp.json`: cada persona se autentica con su cuenta (OAuth) la primera vez con `/mcp`. Las credenciales nunca van en git.
